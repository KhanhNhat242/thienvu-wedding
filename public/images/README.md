# Nguồn ảnh (R-CONTENT 3)

Toàn bộ ảnh trên trang là **ảnh thật của studio**, dùng trực tiếp từ `library/`. Không có ảnh stock hay ảnh AI.

| Thư mục / file | Nội dung |
|---|---|
| `library/` | 56 ảnh gốc độ phân giải cao (960–2048px) của studio |
| `main-logo.jpg` | Logo gốc (chữ đè lên ảnh cưới) — nguồn của `logo/` |
| `logo/` | `logo-moss.png`, `logo-ivory.png` — chữ THIENVU tách nền; dòng "WEDDING STUDIO" dựng bằng font serif trong `components/ui/Logo.tsx` |

**Vị trí ảnh nào dùng file nào:** xem `data/images.ts`. Muốn đổi ảnh một vị trí, chỉ sửa tên file ở đó.

Lưu ý khi chọn ảnh: tránh ảnh có chữ/đồ hoạ in đè (bìa "Best Couture", "Journal", "Romance"…) cho các khung ảnh lớn.

`app/icon.png` và `app/opengraph-image.jpg` được tạo từ logo + ảnh hero.
